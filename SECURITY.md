# Security notes — V2.3.0

- Default credentials \`root / creality_2024\` are vendor/default values required by the project; users may override them.
- Passwords are never persisted to \`settings.json\`.
- Host/IP, SSH user and key path persist only when **Remember connection** is explicitly enabled.
- Generated private SSH keys stay local and are never included in logs or Backup archives by the application.
- Installing a public key is a printer write and always requires an explicit user action/confirmation.
- Pause/Resume are printer actions and require explicit user action.
- Configuration Backup is read-only on the printer. V2.3.0 uses SSH TAR streaming and does not invoke SFTP.
- Backup TAR paths are validated against absolute/traversal members; symlinks are recorded in the manifest but not dereferenced locally.
- Backup archives may themselves contain credentials, network configuration or other sensitive printer configuration. Keep them private unless separately sanitized.
- SSH currently uses Paramiko \`AutoAddPolicy\`; an unknown host key is accepted automatically. Use SSH functions only on a trusted network and confirm that the target host is your printer.
- RSA private keys generated by the application are stored locally as unencrypted key files. Protect the local key file with normal OS access controls and do not publish or include it in support bundles.
